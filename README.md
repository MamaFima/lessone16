
Этот проект представляет собой веб-приложение, разработанное с использованием Python и HTML, предназначенное для демонстрации навыков веб-разработки и обработки данных.

## Структура проекта

- **`main.py`**: основной файл приложения, содержащий логику работы сервера.
- **`templates/`**: директория с HTML-шаблонами для рендеринга веб-страниц.
- **`static/`**: папка для статических файлов, таких как изображения и стили.
- **`dz1.py`, `dz2.py`, `dz3.py`**: дополнительные скрипты, вероятно, связанные с различными заданиями или функциональными модулями.
- **`.gitignore`**: файл, определяющий, какие файлы и директории должны быть проигнорированы Git.
- **`LICENSE`**: файл с информацией о лицензии проекта (MIT License).

## Установка и запуск

1. **Клонирование репозитория**:
   ```bash
   git clone https://github.com/MamaFima/lessone16.git
   cd lessone16
   ```
2. **Установка зависимостей**:
   Убедитесь, что у вас установлен Python 3.x. Затем установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. **Запуск приложения**:
   ```bash
   python main.py
   ```
   После этого приложение будет доступно по адресу `http://127.0.0.1:5000/` или указанному в настройках порту.

## Использование

После запуска приложения вы сможете взаимодействовать с ним через веб-интерфейс. Функциональность зависит от реализации в файлах `main.py` и соответствующих шаблонах в директории `templates`.
